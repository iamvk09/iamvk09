## About Me

I'm a final-year Computer Science Engineering student at **RV Institute of Technology and Management, Bengaluru**, focused on building practical software systems that solve real-world problems.

My work spans machine learning, explainable AI, full-stack development, and data-driven product engineering. I enjoy taking an idea from problem definition through implementation, evaluation, deployment, and documentation.

I approach engineering with an emphasis on measurable results, maintainable code, understandable model behavior, and useful user experiences.

- **Software Engineering:** Designing application architectures, REST APIs, data pipelines, and maintainable software.
- **AI/ML Engineering:** Building predictive models, evaluating algorithms, and interpreting model decisions.
- **Full-Stack Development:** Connecting frontend interfaces, backend services, databases, and deployed applications.
- **Product Engineering:** Turning technical concepts into functional prototypes and deployable applications.
- **Research:** Exploring applied machine learning, explainable prediction systems, and engineering applications of AI.

**Open to:** Software Engineering opportunities, AI/ML internships and entry-level roles, research collaborations, and open-source contributions.

<summary><strong>01. Crop Failure Risk Prediction Using AI</strong></summary>

<br>

An agricultural decision-support application that estimates crop failure risk using machine learning and weather-related factors. The project combines predictive modelling, geographic visualization, and risk interpretation to explore how data-driven tools can support agricultural decisions.

**Live Application:** [reducecropfailure.onrender.com](https://reducecropfailure.onrender.com/)

|---|---|

| Security | Academic prototype; no independent security audit published |

**Engineering Highlights**

- Developed a machine learning pipeline for agricultural risk prediction.
- Compared algorithms using classification evaluation metrics.
- Implemented risk categorization and model interpretation.
- Built an interactive dashboard with geographic visualization.
- Deployed the application for public demonstration.

**Research Publication:** [Read the published paper](https://doi.org/10.55041/ijcope.v2i5.049)

**Live Application:** [Hugging Face Spaces](https://huggingface.co/spaces/iamvk09/predictive-maintenance-lgbm)

|---|---|

| Scale | AI4I 2020 Predictive Maintenance Dataset; 10,000 instances |
| Performance | Recorded evaluation: 97.85% accuracy, 0.7514 F1-score, 95.59% recall |
| Security | Research prototype; no independent security audit published |
| Impact | Combines equipment failure prediction with interpretable model outputs |
| Repository | [Industrial-Predictive-Maintenance](https://github.com/iamvk09/Industrial-Predictive-Maintenance) |

**Research Highlights**

- Evaluated machine learning algorithms on industrial telemetry data.
- Explored class imbalance during model training.
- Applied SHAP to interpret model predictions.
- Integrated model inference with an interactive application.
- Co-authored research published in May 2026.

</details>
